# Bikram Ray — Architecture Portfolio

Responsive, static architecture-portfolio starter. It requires no framework, build step, backend or environment variables.

## Preview locally

Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Deploy on Vercel

1. In [Vercel](https://vercel.com/new), import `Bivekumarsah/bikramray-portfolio`.
2. Select **Framework Preset: Other**; leave the build command empty. The site is served from the repository root.
3. Deploy. Your generated `*.vercel.app` address works before you buy or link a domain.
4. Later, in the project's **Settings → Domains**, add `bikramray.com.np` (and optionally `www.bikramray.com.np`). Follow the DNS records Vercel provides at your domain's DNS manager. Do not set DNS records until you receive the exact records from Vercel.

## Customize before publishing

- Replace the sample Unsplash photography in `index.html` and `styles.css` with original project images.
- Replace the sample project names, descriptions and approach text with verified work and your own biography.
- Replace `hello@example.com` in `index.html` with a real contact address.
- Update the page title, meta description and social sharing text if needed.
- Replace the included BR favicon with your own brand identity when ready.

## Files

- `index.html`: main page and editable content
- `styles.css`: styling and responsive layout
- `script.js`: mobile navigation and dynamic copyright year
- `favicon.svg`: temporary brand icon
- `vercel.json`: static hosting settings and security headers

The listed projects are **placeholders, not claims of completed work**.
